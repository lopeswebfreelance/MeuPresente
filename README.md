# Minha Lista de Desejos - Aniversário 

Bem-vindo ao repositório do meu projeto de **Lista de Desejos**. Esta é uma aplicação web elegante, leve e responsiva, desenvolvida para ajudar amigos e familiares a escolherem e reservarem presentes de forma prática, integrada diretamente com links de lojas parceiras e suporte a contribuições via Pix.

## Funcionalidades

- **Mapeamento de Preços:** Apresenta de forma transparente o preço aproximado de cada item antes do redirecionamento.
- **Abertura Inteligente:** Links otimizados que abrem as lojas em novas abas sem bloquear a navegação.
- **Fluxo de Confirmação:** Modais interativos que guiam o convidado a confirmar se a compra foi concluída para atualizar a lista automaticamente.
- **Módulo de Contribuição:** Janela integrada para exibição de QR Code e valores dinâmicos para quem optar por enviar um Pix.
- **Interface Fluida:** Design moderno construído com CSS customizado, paleta de cores harmoniosa e efeito visual de itens já reservados.

## Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página e dos modais.
- **CSS3:** Estilização baseada em variáveis nativas (`:root`), Grid Layout para responsividade e animações fluidas para as janelas.
- **JavaScript (Vanilla):** Lógica assíncrona para renderização do catálogo de produtos, controle de estados de compra e gerenciamento dos modais.
